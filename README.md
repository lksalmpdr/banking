# 🏦 Banking App

Bem-vindo ao repositório do **Banking App**, uma aplicação desenvolvida em **React** para simular operações bancárias essenciais. Este projeto foi criado com foco na gestão de dados de clientes e controle de transações financeiras.

## 🚀 Funcionalidades

O aplicativo conta com as seguintes funcionalidades principais:

### 👤 Dados do Cliente
- **Perfil do Usuário**: Visualização e edição de informações cadastrais.
- **Saldo em Conta**: Exibição do saldo atualizado em tempo real.

### 💸 Transações
- **Histórico de Movimentações**: Listagem completa de entradas e saídas.
- **Detalhamento**: Informações detalhadas sobre cada transação (data, valor, tipo).
- **Filtros**: Capacidade de filtrar o extrato por período ou tipo de transação.

## 🛠️ Tecnologias Utilizadas

- **React**: Biblioteca principal para construção da interface.
- **CSS Modules / Styled Components**: Estilização dos componentes (ajuste conforme o projeto real).
- **Context API / Redux**: Gerenciamento de estado global.

## 📦 Como Rodar o Projeto

Siga os passos abaixo para executar a aplicação em seu ambiente local:

### Pré-requisitos
Certifique-se de ter o **Node.js** e o **npm** (ou **yarn**) instalados em sua máquina.

### Instalação

1. Clone este repositório:
```bash
git clone https://github.com/seu-usuario/banking-app.git
```

2. Acesse a pasta do projeto:
```bash
cd banking-app
```

3. Instale as dependências:
```bash
npm install
# ou
yarn install
```

### Execução

Para iniciar o servidor de desenvolvimento:

```bash
npm start
# ou
yarn start
```

O aplicativo estará disponível em `http://localhost:3000`.
